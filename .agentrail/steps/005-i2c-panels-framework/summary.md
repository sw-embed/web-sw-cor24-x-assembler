Added the extensible I2C device-panel framework. src/panels/i2c/{mod,container,tmp101}.rs introduce a BusSnapshot + per-device-snapshot pattern: each run-loop tick polls cor24_emulator's bus state and any attached I2cHandle, writes PartialEq snapshots into use_state, and the I2cPanel re-renders only on change. main.rs attaches a fresh Tmp101Device on each Assemble&Run (the typed handle's weak ref to the bus routing table dies with the EmulatorCore, so each run gets a new attachment) and feeds the snapshot through. Adding a future device is three local changes: new file under src/panels/i2c/, new optional prop on I2cPanelProps, new branch in container.rs's device list.
